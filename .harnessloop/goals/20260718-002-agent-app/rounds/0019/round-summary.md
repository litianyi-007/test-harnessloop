## 结论：距「可试用」最近的那块砖补上了

此前 token 默认值是占位符字符串，**对真内核必然鉴权失败，而 UI 里没有任何地方能填**——
用户双击打开只看到「连接失败」，**没有出路**。加上本仓文档记着 `open` 不继承 shell
环境变量，连「先 export 再打开」对普通用户也不通。

现在有 ⌘, 设置面板：token 存 **Keychain**、endpoint 存 UserDefaults、优先级
`env > 已存设置 > 默认`，**且界面显示当前生效值来自哪一个来源**。

## 三条硬约束，每条都有它存在的理由

| 约束 | 为什么 |
|---|---|
| token 只进 Keychain | 本仓 PUBLIC 且有过凭证泄漏事件；plist 是明文、进备份、可被 `defaults read` 读出 |
| env 优先于界面设置 | repro 脚本与 CLIRunner 靠环境变量驱动，反过来会**静默破坏**既有流程 |
| **必须显示来源** | 只做优先级不显示来源 = 制造一个新的「设置了却没生效」类静默失败 |
